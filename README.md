# LingBot-Map courthouse point cloud

A color point cloud reconstructed from 16 publicly available courthouse frames in the [LingBot-Map](https://github.com/Robbyant/lingbot-map) example dataset using the [community online demo](https://huggingface.co/spaces/oualidD4/lingbot-map-3d).

- Frames: 16 at 518 × 294
- Points: 974,669
- Model file: `scene.glb` (glTF 2.0)

[Open the smaller point-cloud preview in an online viewer](https://gltf-viewer.donmccurdy.com/#model=https%3A%2F%2Fcdn.jsdelivr.net%2Fgh%2Fbitdeepcode%2Flingbot-map-courthouse-viewer%40main%2Fscene_preview.glb&cameraPosition=1.026%2C0.304%2C1.443). The preview samples about one quarter of the original points. The full-resolution result is `scene.glb`.

The scene contains visible streaks and noise because it uses only a short sequence. It is a point cloud, not a watertight mesh.
